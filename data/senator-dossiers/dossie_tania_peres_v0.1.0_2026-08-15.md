# 22. Regra de uso deste arquivo

Este dossiê pode alimentar:

- `historico_politico`;
- `plataforma`;
- sistema de evidências;
- pesquisa complementar;
- comparação entre candidaturas.

Não deve alimentar artificialmente:

```text
legislative_votes
```

ou:

```text
impact_score
```

sem que um voto parlamentar real seja encontrado.

## Campos factual/documentais

- nome;
- candidatura;
- cargo;
- partido;
- IDs;
- vínculos institucionais;
- cargo funcional;
- representação sindical;
- eleição para o Consun;
- votos recebidos no Consun;
- participação documentada em reuniões/mobilizações;
- declarações atribuídas por fonte.

## Campos derivados/revisáveis

- temas;
- beneficiary group;
- impact direction;
- confidence;
- interpretação de agenda;
- eventual score futuro.

**Princípio de auditoria:** quando não existe mandato legislativo, o sistema deve dizer isso claramente. Inventar um “histórico de votação” para tornar todos os candidatos comparáveis seria uma comparação bonita, limpa e completamente falsa.
