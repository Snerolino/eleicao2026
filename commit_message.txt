🛡️ Sentinel: [Medium] Fix potential XSS via unsanitized source URL in AdminPage

🚨 Severity: MEDIUM
💡 Vulnerability: AdminPage rendered dynamic source URLs (claim.source_references.url) into href attributes without prior sanitization, posing a Stored XSS risk if an attacker injected malicious protocols like `javascript:`.
🎯 Impact: An admin reviewing claims might click a malicious link, resulting in JavaScript execution under their privileged session.
🔧 Fix: Wrapped the URL output in the `sanitizeUrl` utility from `@/utils/sanitizeUrl` to validate allowed protocols. Also added `noopener` to the anchor tag for defense-in-depth.
✅ Verification: Build and vitest suite passed successfully.
